# Synthetic standing release

Approved standing can be relinquished only before its one claim draft is opened. A release must be an authenticated personal command with an exact receipt, immutable history and current actor checks. Historical review evidence remains immutable. An opened claim cannot be released through this path; its existing controlled succession applies.

This engineering slice is incomplete until the required database and browser acceptance gates pass. It grants no real probate, account transfer, or eligibility finding.

No existing filing is automatically displaced by an assertion of competing standing.
