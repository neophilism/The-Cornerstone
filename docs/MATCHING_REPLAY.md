# Frozen Exchange continuation transcript replay

This is an independently reviewable, pure TypeScript replay adapter contributing to **CS-20**. It does not create an Exchange, hold sealed choices, witness a draw, authenticate participant consent, establish an official ranking, or authorize any compact. All inputs are synthetic until a separate verified custody/provider boundary exists.

`replayFailedMatches(round, events)` starts from the original validated matching result. Each numbered event must record the exact active allocation before a failed pair, the failed pair, the unique willing applicants, and the claimed successor allocation. The verifier requires an uninterrupted 1-based sequence and rejects any mismatched before/after snapshot, ineligible pair, inactive failure, regressed choice, duplicate active holding, contradictory prior failure or attempt to rewind a frozen ranking. It recomputes each successor using `continueFailedMatch` and its cumulative declined-pair history. Before/after arrays may be permuted without changing meaning; applicant ranking and fixed draw order may not.

The returned initial/final allocations and per-event snapshots are copied from the verified computation, not taken verbatim from the proposed after-states. This prevents a caller's asserted allocation from silently replacing the computation. Independent source and event authenticity remains unsolved: an attacker able to replace the round and every associated event can still build a self-consistent false transcript. Binding rounds to sealed encrypted rankings, witness-signed releases, immutable storage and custody/authorization is separate future work. Never label this proof as independent acceptance.

The Vitest replay suite exercises a three-step unsuccessful-negotiation history, cumulative non-rewind advancement, preserved active allocations, expected initial allocation, deterministic replay, input immutability, missing/reordered sequences, altered proposed state, tampered willingness and repeated failures. The existing matching reference tests remain mandatory.
